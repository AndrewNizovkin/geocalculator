# web-client

Включает в себя клиентскую часть приложения, работающую в браузере пользователя. 
Предоставляет графический интерфейс для решения прикладных задач геодезии:

- Каталог координат. Предоставляет возможность создавать, читать из текстового файла,
редактировать базу данных трёхмерных координат точек, которая может быть использована 
при решении других задач в системе.

- Топографическая съёмка. Предоставляет инструменты для редактирования и обработки результатов тахеометрической съёмки, извлечения тахеометрического хода из полевых измерений. 
Исходные данные могут вводиться вручную или импортироваться из файлов электронных тахеометров. 
Отображает, полученные в результате математической обработки каталоги и ведомости координат, 
схему измерений. 

- Полигон. Предоставляет инструменты для редактирования и обработки одиночного тахеометрического хода. Отображает, полученные в результате уравнивания, каталоги, ведомости уравнивания в плане и по высоте.

- Прямая геодезическая задача.

- Обратная геодезическая задача.

- Обратная геодезическая засечка. Задача Потенота.


Используемые технологии:

- HTML

- CSS

- JavaScript
