# Geocalculator_service

## Запуск сервера

По умолчанию сервер использует порт: 8181.

Для сборки  и запуска docker-контейнера `geocalculator_container` следует указать абсолютный путь к рабочей директории в файле `Dockerfile`.

Запуск из директории проекта, содержащей файл `docker-compose.yaml` командой:

```bash
docker-compose up -d
```

## API

### `/direct` 

POST-запрос. Предоставляет решение прямой геодезической задачи. 

> Определяет пространственные координаты цели по результатам линейно угловых измерений, выполненных с базиса с известными координатами наблюдатеной станции и ориентира. 

Тело запроса `DirectTaskRequest` включает:
    
|свойство|тип|Описание|
|-|-|-|
|landmarkX|long|Координата X ориентира, мм.| 
|landmarkY|long|Координата Y ориентира, мм.| 
|landmarkDirection|long|Направление на ориентир, сек|
|baseX|long|Координата X базы|
|baseY|long|Координата Y базы|
|baseZ|long|Координата Y базы|  
|baseHeight|long|Высота инструмента над точкой, мм.|
|targetDirection|long|Направление на цель, сек.|
|targetInclinedDistance|long|Наклонное расстояние между базой и целью, мм.|
|targetTiltAngle|long|Угол наклона измеренной линии, сек.|
|targetHeight|long|Высота цели над определяемой точкой, мм.|

Тело ответа `DirectTaskResponse` включает:

|свойство|тип|Описание|
|-|-|-|
|targetX|long|Координата X определяемой точки, мм.|
|targetY|long|Координата Y определяемой точки, мм.|
|targetZ|long|Координата Z определяемой точки, мм.|

### `/inverse`

|targetZ|long|Координата Z определяемой точки, мм.|

Тело ответа `InverseTaskFullResponse` включает следующие поля:

|свойство|тип|Описание|
|-|-|-|
|baseX|long|Координата X базы, мм.|
|baseY|long|Координата Y базы, мм.|
|baseZ|long|Координата Y базы, мм.|  
|targetX|long|Координата X определяемой точки, мм.|
|targetY|long|Координата Y определяемой точки, мм.|
|targetZ|long|Координата Z определяемой точки, мм.|
|direction|long|Дирекционный угол линии, сек.|
|horDistanse|long|Горизонтальное проложение, мм.|
|inclinedDistanse|long|Наклонное расстояние, мм.|

|elevation|long|Превышение цели над базой, мм.|

### `/survey/import`

POST-запрос. Производит импорт полевых измерений во внутренний формат системы из электронных тахеометров.

**Тело запроса включает в себя список (массив) строк.**

Первая строка содержит информацию об источнике импорта `import-leica`, `import-nikon`, ...

Остальные строки запроса содержат импортируемые данные соответствующего типа.

**Тело ответа включает в себя список (массив) строк.**

Первый блок строк описывает параметры станций. 

Каждая строка содержит значения свойств, разделённые символом пробела:

```txt
stationName stationX stationY stationZ stationHeight orName orX orY
```

|свойство|диапазон значений|описание|
|-|-|-|
|stationName|любые символы кроме пробела|Название станции|
|stationX|любое число|Координата X станции, м.|
|stationY|любое число|Координата Y станции, м.|
|stationZ|любое число|Координата Y станции, м.|
|stationHeight|любое число|Высота инструмента, м.|
|orName|любые символы кроме пробела|Название ориентира|
|orX|любое число|Координата X ориентира, м.|
|orY|любое число|Координата Y ориентира, м.|

Блок станций заканчивается строкой разделителем `//`.

Далее следуют блоки строк, описывающие измерения на станциях. Количество блоков измерений соответствует количеству станций. Блоки разделены строкой разделителем `//`.

Каждая строка содержит значения свойств, разделённые символом пробела:

```txt
targetName targetInclinedDistance targetDirection targetTiltAngle targetHeight stationIndex
```

|свойство|диапазон значений|описание|
|-|-|-|
|targetName|любые символы кроме пробела|Название цели (пикета)|
|targetInclinedDistance|неотрицательное число|Наклонное расстояние, м.|
|targetDirection|неотрицательное число в формате г.ммсс|Направление на цель|
|targetTiltAngle|число в формате г.ммсс|Угол наклона линии на цель|
|targetHeight|любое число|Название цели (пикета)|
|stationIndex|неотрицательное целое число|Индекс станции|

**Тело запроса включает в себя список (массив) строк.**

Первый блок строк описывает параметры станций. 

Каждая строка содержит значения свойств, разделённые символом пробела:

```txt
stationName stationX stationY stationZ stationHeight orDirection orName orX orY
```

|свойство|диапазон значений|описание|
|-|-|-|
|stationName|любые символы кроме пробела|Название станции|
|stationX|любое число|Координата X станции, м.|
|stationY|любое число|Координата Y станции, м.|
|stationZ|любое число|Координата Y станции, м.|
|stationHeight|любое число|Высота инструмента, м.|
|orDirection|число в формате г.ммсс|Направление на ориентир|
|orName|любые символы кроме пробела|Название ориентира|
|orX|любое число|Координата X ориентира, м.|
|orY|любое число|Координата Y ориентира, м.|

Блок станций заканчивается строкой разделителем `//`.

Далее следуют блоки строк, описывающие измерения на станциях. Количество блоков измерений соответствует количеству станций. Блоки разделены строкой разделителем `//`.

Каждая строка содержит значения свойств, разделённые символом пробела:

```txt
targetName targetInclinedDistance targetDirection targetTiltAngle targetHeight stationIndex
```

|свойство|диапазон значений|описание|
|-|-|-|
|targetName|любые символы кроме пробела|Название цели (пикета)|
|targetInclinedDistance|неотрицательное число|Наклонное расстояние, м.|

|stationIndex|неотрицательное целое число|Индекс станции|

Первый блок строк начинается строкой-заголовком `#survey-report` и представляет каталоги координат точек в формате:


|z|любое число|Координата Y точки, м.|

Каждый блок отделён от других строкой разделителем `//` и начинается с координат станции и ориентира

Второй и заключительный блок сводного отчёта начинается строкой заголовком `#processing-report` и представляет строки ведомости вычисления координат.
